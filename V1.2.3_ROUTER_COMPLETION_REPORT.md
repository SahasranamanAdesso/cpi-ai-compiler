## Limitations & Future Work

### ⚠️ NOT YET IMPLEMENTED

The following Router features require additional work:

#### 1. Sequence Flow Conditions
**Current**: Sequence flows are simple connections  
**Required**: Conditional routes with conditionExpression  
**Evidence**: SAP lines 964-1013

**Example**:
```xml
<bpmn2:sequenceFlow id="..." name="POST" sourceRef="Gateway_1" targetRef="...">
    <bpmn2:extensionElements>
        <ifl:property><key>expressionType</key><value>NonXML</value></ifl:property>
        <ifl:property><key>componentVersion</key><value>1.0</value></ifl:property>
        <ifl:property><key>cmdVariantUri</key><value>ctype::FlowstepVariant/cname::GatewayRoute/version::1.0.0</value></ifl:property>
    </bpmn2:extensionElements>
    <bpmn2:conditionExpression xsi:type="bpmn2:tFormalExpression">${header.method} = 'POST'</bpmn2:conditionExpression>
</bpmn2:sequenceFlow>
```

#### 2. Default Route Attribute
**Current**: Gateway has no default attribute  
**Required**: `<bpmn2:exclusiveGateway default="SequenceFlow_X">`  
**Evidence**: SAP line 932

#### 3. BpmnProcessMapper Router Support
**Current**: Router connections treated as simple flows  
**Required**: Map Router.getRoutes() to conditional sequence flows  
**Impact**: Routes defined in Router model not serialized to BPMN
