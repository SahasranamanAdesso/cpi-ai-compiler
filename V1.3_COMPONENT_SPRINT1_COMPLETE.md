#### SDK Usage

```typescript
const multicast = new Multicast("Send to Multiple Systems");

flow.addComponent(multicast);
flow.addComponent(crmReceiver);
flow.addComponent(warehouseReceiver);
flow.addComponent(billingReceiver);

// All branches execute in parallel (no conditions)
flow.connect(multicast, crmReceiver);
flow.connect(multicast, warehouseReceiver);
flow.connect(multicast, billingReceiver);
```

#### Architecture Changes

**New Writer**:
- `ParallelGatewayWriter` - Generates `<bpmn2:parallelGateway>` BPMN element
- Pattern: Based on ExclusiveGatewayWriter, no default route attribute

**Mapper Updates**:
- `BpmnProcessMapper.ts` - Detects Multicast, creates simple sequence flows (no conditions)
- `ProcessWriter.ts` - Routes parallelGateway to ParallelGatewayWriter
