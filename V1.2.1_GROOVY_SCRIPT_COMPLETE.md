## Resource Model Explanation

### Architecture

```
IFlow
├── Components (BPMN nodes)
├── Connections (BPMN flows)
└── Resources (External artifacts)
     ↓
GroovyResource implements Resource
     ↓
IflowPackager.packageResources()
     ↓
ZIP bundle: src/main/resources/script/transform.groovy
```

### Key Design Decisions

1. **Resources as First-Class Citizens**
   - Resources are owned by IFlow, not Components
   - Allows reusing resources across components
   - Clean separation of concerns

2. **Generic Resource Interface**
   - GroovyResource is just one implementation
   - Future: MappingResource, XsdResource, XsltResource
   - Packager handles all types generically

3. **Inline or Filesystem**
   - Small scripts: inline content
   - Large scripts: filesystem path
   - Packager abstracts the difference

4. **SAP Conventions Enforced**
   - `groovy` → `script/` directory
   - `mapping` → `mapping/` directory
   - `xsd` → `schema/` directory
   - Follows SAP Integration Suite standards

## Lessons Learned

### What Worked Well

1. **Registry Metadata Design**
   - Single source of truth
   - Easy to verify against real SAP artifacts
   - No guessing required

2. **Generic Writers**
   - CallActivityWriter handles all components
   - No duplication across component types
   - Maintainability validated

3. **Resource Abstraction**
   - Clean separation: Component (BPMN) vs Resource (artifact)
   - Packager handles all resource types generically
   - Extensible pattern

### What to Watch

1. **Resource References**
   - Component.properties.scriptReference must match Resource path
   - Currently manual - could add validation helper
   - Consider builder pattern for complex cases

2. **Resource File Paths**
   - Filesystem paths are relative to example script location
   - Could cause issues if paths not carefully managed
   - Document best practices

3. **Registry Metadata Verification**
   - Currently based on SAP exports
   - No automated verification against live SAP system
   - Future: integration tests with real Import API
